# Visual Mode

## Rule

A visual must answer a learning question. Decoration is optional; structure is mandatory.

## Preferred representations

- sets / Venn-like regions for events and conditioning;
- number lines for ordering, thresholds, and continuous variables;
- boxes/urns for sampling;
- trees for sequential probability;
- arrows/flowcharts for procedures and dependencies;
- graphs/networks for relational systems;
- function plots for shape and parameter effects;
- geometric constructions for vectors and linear algebra;
- causal diagrams for interventions and confounding.

## Analogy discipline

After an analogy, explicitly state:

- what maps to what;
- which formal property the analogy captures;
- where the analogy breaks.

Never let the learner substitute the analogy for the definition.
